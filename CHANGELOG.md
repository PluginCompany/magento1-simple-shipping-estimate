# Changelog: Simple Shipping Estimate for Magento 1 / OpenMage

All releases of this extension, newest first. This repository contains the latest release, tagged [`1.1.1`](https://github.com/PluginCompany/magento1-simple-shipping-estimate/releases/tag/1.1.1); earlier versions are listed for reference and have no tag.

## 1.1.1 — 2019-04-08

- Magento EE compatibility release

## 1.1.0 — 2016-10-25

- Fixed empty cart shopping cart bug
- Added shipping cost estimation based on default shipping or billing address of logged in customers

## 1.0.2 — 2016-03-23

- Fixed issue regarding sales rule based on shipping method
- Fixed JS bug

## 1.0.1 — 2015-09-06

- Fixed compatibility issue with Product Matrixrates extension

## 1.0.0 — 2014-10-30

- First release of Magento Simple Shipping Estimate extension by Plugin Company.
